# Field Shift: Adapting Farms with NASA Data

¿Qué conviene sembrar después de la cosecha si el suelo necesita cobertura, pero el agua puede escasear antes de la próxima siembra? **Field Shift** es una propuesta para el NASA Space Apps Challenge 2026 que busca ayudar a agricultores a comparar rotaciones de cultivos. La comparación combinará observaciones de la Tierra de la NASA con el historial del predio, las características de los cultivos y las prioridades de quien lo trabaja.

**Estado del proyecto:** diseño inicial. Este repositorio comienza con la definición del problema y el alcance propuesto para un primer prototipo.
